# Project Nexus — 実装開始記録

作成日: 2026-10-28

## 今回実施したこと

- 既存の公開リポジトリを読み取り、実装が静的LPと統合マインドマップに限定されていることを確認。
- Google DriveのProject Nexusホワイトペーパーと資産台帳を読み取り、主張・出典・検証状態を分離。
- 未検証のウォレット、トークン、スマートコントラクト、AI自動化稼働実績を事実として公開しない方針を採用。
- `/vault` 相当の公開安全版 `vault.html` を追加し、資料上の記録と未検証項目を検索・分類できるようにした。
- `data/evidence-summary.json` に集計値・主張・優先アクションを格納した。

## 次の実装単位

1. 秘密情報の有無を値を収集せずにスキャンする。対象はローカル、GitHub履歴、Driveの公開範囲。
2. 資産台帳を `source / claim / identifier / chain / verification_status / last_checked_at / sensitivity` に正規化する。
3. 検証モジュールを読み取り専用で追加する。ブロックエクスプローラーの公式URL、トランザクション、コントラクトアドレスが揃った行だけを対象にする。
4. 検証ログとテストを追加する。人間の承認なしに投稿・送金・コントラクト操作を実行しない。
5. データ公開範囲を `public / internal / restricted` に分け、公開ビルドへは `public` のみを含める。

## 非目的

- 秘密鍵、シード、リカバリーフレーズ、APIキーの取得・移動・保存。
- 未検証の資産や所有権の断定。
- SNS自動投稿、送金、スマートコントラクトの書き込み。
- Google Drive上の原本の変更・削除。
