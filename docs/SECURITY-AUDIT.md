## 公開時の禁止事項

- シード、秘密鍵、APIキー、パスワード、個人情報をリポジトリ・検索インデックス・共有Docsへコピーしない。
- ウォレットアドレスだけで所有権や価値を断定しない。
- スクリーンショットを一次証拠として扱わず、公式URL・トランザクション・取得日時を紐付ける。
- 原本や個人・金融・相続関連資料を公開用ナレッジベースへ混在させない。
